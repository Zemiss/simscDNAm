# 新增两基线实施计划

当前运行采用统一 Subclass 过滤。各配置在原训练划分中统计类别频数，训练不足 10 个细胞的类别从训练和测试同时移除。现有六种方法及 Liu2023 全量消融都在过滤后重跑，A3 参照也重新拟合。以下保留过滤前的接入计划和接口约定。

目标：移除旧空间转录组基线的当前代码、文档、结果及图中条目，新增 PeakVI、DiTSim；不修改其它方法的矩阵、模型、划分或指标。

新增方法统一只使用真实训练集逐区域中位数填补，保留真实零值、完整区域轴及训练前已存在的 1000 个复制区域。整列无观测时使用训练中有限中位数的总体中位数，不读取测试表达值。生成后仅 `clip(0,1)`，不进行缺失掩码、联合秩映射、特征筛选或额外归一化。生成细胞总数和逐 Subclass 配额与测试集一致。

1. 核对并固定官方版本和接口。PeakVI 保持原生可及性损失，使用官方随机后验可及性概率接口，按训练同类型供体行生成目标配额；明确区别于先验采样。DiTSim 沿用官方 quick_start 的 AE/DiT 架构与正式训练参数。
2. 先验证中位数填补不利用留出值、真实零值保持、缓存来源变化拒绝复用和输出只裁剪。各接口以小型真实调用检查后再正式运行。
3. 实现训练与生成 Notebook，各 Python 入口仅传递路径、种子和设备并执行 Notebook，导入不训练。函数放在 Notebook 内部，共用预处理函数放 data。
4. 在服务器 simscDNAm 环境中安装所需兼容依赖，所有产物写入授权 outputs。对十个既有配置运行新增两个方法，计算现有五项指标；恒定输出造成未定义指标时保留未定义状态，不补造分数。
5. 保留其它四方法既有分数，更新十张表和全量比较图；保留消融矩阵及其数值。扫描工作区和服务器当前代码、产物及归档，去除已删除方法的内容。最后核对新三者配额、区域轴、数值范围和未改动原有输入，关闭本轮内核。

验收：两个官方接口来源及版本可追溯；十配置新增矩阵形状和类型配额正确、数值有限且位于 0–1；旧四方法矩阵指纹与五项分数不变；全部改动位于 main，不创建分支。
