# 30近邻：simscDNAm、三个baseline及全量消融

本次将miLISI统一为30近邻，仍排除中心细胞、使用真实Subclass、按各类型miLISI中位数等权平均。全量、九个GSE子集共10张四方法表，另含全量四版本消融，共44行、220个有效指标值。A1/A2不依赖近邻数，逐值复用并核对原结果；A3全部重新计算。旧10近邻结果保留为历史，不以修改参数标签代替重算。

固定原权重、合成矩阵、真实训练参照和外层划分，没有重新训练、生成、选择checkpoint或调映射。全量与消融复用冻结PCA坐标；九子集按相同训练参照重算ANOVA50000/PCA50，所有方法的原10近邻总分及类型中位数均回归通过。全量和消融的UMAP也重新使用30近邻，图中miLISI来自PCA空间。

加粗为同表最优。A1 MSE为类型平均甲基化水平的偏差，不是逐元素重建误差。simATAC和simCAS仍使用原生计数／分数，无截断或缩放。

在十组四方法比较中，simscDNAm的1-WD、A1 Pearson、A2 Pearson均在10组最优，miLISI在6组最优；其余4组miLISI由FittedMarginal最优，分别为Liu2021/GSE131360及Tian2023的三个子集。MSE在十组均由FittedMarginal最优。

全量消融中，完整模型的miLISI为1.66503，仅mask版本为1.88583；更强边缘适配仍伴随混合指标下降。不同近邻数改变观察尺度，不能将10变30后的分数上涨解释为模型质量改善。

现有checkpoint保留其原10近邻内部选模历史；未来训练入口已改为30近邻。本轮仅改变评估协议。当前数据划分曾多轮查看，尚无新的独立供体或外部盲测。

消融中的mask指生成后的同类型真实缺失掩码，不是训练损失的缺失处理。各自有效的A2配对数依次为1000、964、1000、963；共同有效的963对上，Pearson依次为0.979480、0.980430、0.999856、0.999896。同一配对内的有效细胞仍可不同。Mask未修改保留位置的生成值。完整模型缺失率20.173%，真实留出为20.147%，无mask版本为0。

小类型沿用原规则：fit少于5或内部验证少于3时不做数值映射；例如Liu2021/GSE131354仅10/65个细胞发生对齐。高复制Pearson来自联合映射后处理，不能归因于CVAE自主学会结构。
